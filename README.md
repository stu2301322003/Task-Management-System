# Task-Management-System
This project introduces a web application designed to make task management simple and efficient. The main idea is to assist team managers with task allocating and tracking in live production environments. The system's functionality can be applied to different types of devices including mobile, IoT, ESP32, allowing for its implementation into different devices.

If you are a manager of a 15-man team and want to keep up with the daily task board you need to have a lot of hands and eyes in every place. Create a preliminary task list and assign it to your team. The system notifies about the daily tasks and allows teammates to follow up and mark their tasks as 
### Completed, 
### With Complications, 
### On track, etc. 

Tracking tasks has not been easier.
